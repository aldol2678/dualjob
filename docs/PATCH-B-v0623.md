## 저장·미리보기·되돌림

- 저장 키, 외부 패킷 스키마 1, 도전 `version:4`, 전문화 `contentRevision:21` 유지.
- 선택 필드 `turnDiscard`는 이번 턴에 사용한 카드 사본 수다. 실제 카드는 기존 `discard` 배열에 그대로 남는다. 같은 이름의 사본은 개수로 구분한다.
- 구버전 저장에 필드가 없으면 빈 기록으로 불러온다. 불러온 턴의 과거 사용 이력을 추측하지 않으며 이후 사용부터 추적한다. 이번 변경은 이어하던 도전에도 적용된다.
- 재시작/새 전투/턴 종료에서 기록을 초기화한다. 백업과 새로고침은 현재 턴 기록을 보존한다. 잘못된 ID·음수·소수·실제 버림 더미보다 많은 사본 수는 거부한다.
- 미리보기는 복제 상태에서 같은 순환 규칙을 사용한다. 카드 보존·동일 사본 재뽑기 방지·이전 턴의 다른 사본 허용을 검사했다.
- 구버전으로 되돌려도 카드는 기존 배열 안에 있으므로 새 필드 때문에 사라지지 않는다. 다만 구버전의 재순환 문제가 돌아온다. 실제 운영 롤백은 수행하지 않았다.
- 보스는 이미 화면에 표시된 행동과 기존 저장의 준비 피해 수치를 유지한다. 저주로 체력 경계를 넘겨도 그 적 턴에 갑자기 적발로 바뀌지 않는다.
