# 에셋

이미지와 폰트는 `src/assets/`에 있습니다. 파일명에 해시를 사용한 원본 에셋은 그대로 보존했습니다. `game.js`의 이미지 매핑과 `styles.css`의 폰트·배경 선언에서 참조 위치를 찾을 수 있습니다.

- 카드·직업·적·배경: AI 제작 이미지의 게임용 WebP
- 파비콘: 카드 두 장과 번개를 사용한 SVG
- 공유 이미지: AI 제작 홍보 일러스트, 1200×630 JPEG
- Pretendard 일반/굵게 및 Gmarket Sans 굵게: WOFF, 별도 라이선스 고지 포함

빌드 스크립트는 이미지나 폰트를 재생성하지 않고 원본 바이트를 복사합니다. 에셋의 시각적 수정은 원본 파일과 사용 위치를 함께 확인한 뒤 수행하세요. 프로젝트 아트의 재사용 허용 범위는 아직 별도로 정하지 않았습니다.

## v0.6.17 이미지 보강

- 카드: 기존 13종 + 신규 27종 = 40/40종. 피로 카드 포함.
- 유물: 신규 12종 = 12/12종. 상점, 정예 보상, 보유 유물, 구매·보상 확인창에서 같은 에셋을 사용합니다.
- 카드 그림은 상점 목록, 구매·삭제 확인창, 강화 전후 비교에도 연결했습니다.
- 캐릭터 초상화는 기존 직업 4종·적 7종을 유지합니다. 수치·상태를 표시하는 SVG와 메뉴 이모지는 기능 아이콘으로 유지합니다.
- 신규 배포 이미지 39개: 투명 WebP, 카드 384×176, 유물 256×256. 총 1,067,134바이트, 단일 최대 46,462바이트.
- 제작: 내장 image_gen. 원본 비율을 유지한 축소 및 WebP 인코딩만 별도 처리했습니다. 까마귀 깃촉은 image_gen으로 가장자리 대비를 보정했습니다.
- 에셋팩토리: 실제 파일에서 측정한 크기·SHA-256을 전달해 메타데이터 구조를 확인했습니다. 연결 도구는 파일을 읽지 않으므로 시각·엔진·권리 검사를 인증하지 않습니다.

검토: 어두운 게임 배경에서 카드 112px·유물 48px 축소판을 비교했습니다. 일부 신규 카드의 질감은 기존보다 세밀하지만 중심 사물과 계열 색은 구분됩니다. 그림이 효과 설명을 대체하지 않도록 이름·비용·효과 텍스트를 유지했습니다.

검증: 신규 39개 파일 디코딩·알파·규격·해시, 카드 40종·유물 12종 렌더링 및 오프라인 내장, 상점 미리보기의 상태 보존, 모바일 여정 7개 회귀 그룹. 실제 휴대전화 터치·전체화면 동작은 이번 이미지 패치에서 재검증하지 않았습니다.
