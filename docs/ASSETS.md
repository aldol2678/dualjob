# 에셋

이미지와 폰트는 `src/assets/`에 있습니다. 기존 이미지 파일은 보존합니다. 0.7 후보에서는 WOFF 폰트를 글리프가 같은 WOFF2로 교체했습니다. `game.js`의 이미지 매핑과 `styles.css`의 폰트·배경 선언에서 참조 위치를 찾을 수 있습니다.

- 카드·직업·적·배경: AI 제작 이미지의 게임용 WebP
- 파비콘: 카드 두 장과 번개를 사용한 SVG
- 공유 이미지: AI 제작 홍보 일러스트, 1200×630 JPEG
- Pretendard 일반/굵게 및 Gmarket Sans 굵게: WOFF2, 별도 라이선스 고지 포함

빌드 스크립트는 이미지나 폰트를 재생성하지 않고 원본 바이트를 복사합니다. 에셋의 시각적 수정은 원본 파일과 사용 위치를 함께 확인한 뒤 수행하세요. 프로젝트 아트의 재사용 허용 범위는 아직 별도로 정하지 않았습니다.

## v0.6.17 이미지 보강

- 카드: 기존 13종 + 신규 27종 = 40/40종. 피로 카드 포함.
- 유물: 신규 12종 = 12/12종. 상점, 정예 보상, 보유 유물, 구매·보상 확인창에서 같은 에셋을 사용합니다.
- 카드 그림은 상점 목록, 구매·삭제 확인창, 강화 전후 비교에도 연결했습니다.
- 캐릭터 초상화는 기존 직업 4종·적 7종을 유지합니다. 수치·상태를 표시하는 SVG와 메뉴 이모지는 기능 아이콘으로 유지합니다.
- 신규 배포 이미지 39개: 투명 WebP, 카드 384×176, 유물 256×256. 총 1,067,134바이트, 단일 최대 46,462바이트.
- 제작: 내장 image_gen. 원본 비율을 유지한 축소 및 WebP 인코딩만 별도 처리했습니다. 까마귀 깃촉은 image_gen으로 가장자리 대비를 보정했습니다.
- 에셋팩토리: 실제 파일에서 측정한 크기·SHA-256을 전달해 메타데이터 구조를 확인했습니다. 연결 도구는 파일을 읽지 않으므로 시각·엔진·권리 검사를 인증하지 않습니다.

## v0.7 신규 에셋 · 로컬 후보

2026-10-29 제작 완료. 운영 배포 전 후보이며 기존 0.6.17 그림을 삭제하지 않았습니다.

- 융합 카드 4종, 신규 유물 8종, 후반 적 변형 2종에 전용 그림을 연결했습니다. 기본 직업 신규 카드 12종은 기존 그림을 재사용합니다.
- 이미지 생성은 내장 image_gen, 게임용 처리는 비율 보존 축소·투명 WebP 인코딩입니다. 카드 384×176, 유물·적 256×256, 합계 327,556바이트입니다.
- 기존 적 ID와 저장 형식은 유지하며 `variant`에 따라 재고 감사관·겸직 심사관 그림을 고릅니다. 변형이 없거나 알 수 없으면 기존 초상화를 씁니다.
- 신규 SVG 8종(돈·보급·유물·겸직·상점·사건·정예·보스)을 코드에 내장했습니다. 경로 전투·휴식, 덱·피로·미수금은 기존 SVG를 재사용합니다. 모든 장식 이모지를 제거한 작업은 아닙니다.
- 폰트 글리프와 순서를 보존한 WOFF2 전환으로 3,077,700 → 2,201,740바이트, 28.46% 감소했습니다. 한글 음절 555개 누락 0개, 라이선스 고지는 유지합니다. 파일 합계 기준이며 첫 로딩 속도 측정치는 아닙니다.
- CSS 굵기는 400/700으로 정리하고 작은 카드 이름·버튼·유물 제목은 Pretendard, 브랜드·큰 제목은 Gmarket을 사용합니다.
- 보유 유물 목록의 disabled 불투명도를 복구하여 그림·설명이 흐려지지 않게 했습니다. 보유 수 분모도 새 도전의 직업별 15종/기존 도전 12종으로 표시합니다.
