| 로드맵 | 구현 |

판정은 **수정·단순화**다. 새 도움말·전투 시스템을 추가하는 대신 기존 미리보기·규칙·전투 화면을 재사용한다. 핵심 카드 선택·겸직 순서·직업별 운영은 유지한다.

## 저장 및 밸런스

- 저장 키와 스키마, `version:4`, 전문화 의미를 가진 `contentRevision:21`을 유지한다. 표시 버전만 0.6.22다.
- `enemiesDefeated`는 선택적 통계 필드다. 새 도전은 0부터 시작한다. 이전 저장에서 누락된 값은 `null`로 두고 결과에 ‘이전 저장 미집계’를 표시한다. 과거 처치 수를 전투 횟수로 추정하지 않는다.
- 미리보기의 처치는 복제 상태에만 반영된다. 실제 진행·저장·누적 기록은 바꾸지 않는다.
- 카드·적 수치, 자원 상한, 전문화 효과, 경로 보상은 변경하지 않았다. 자원 기록의 표시값만 실제 증가량으로 맞췄다.
- 되돌림은 이 패치의 코드 커밋을 되돌리는 방식이다. 이전 코드는 추가 통계 필드를 게임 규칙에 사용하지 않는다. 실제 사용자 백업은 저장소에 포함하지 않는다.
