# v0.6.18 모바일 가독성·에너지 개편

- 에너지/턴 종료를 손패 바로 위에 배치. 배터리 SVG는 0·1·2·3·4 이상 다섯 상태, 실제 숫자는 별도 텍스트.
- 카드 선택 시 같은 시뮬레이터로 사용 후 에너지 표시. 카드 자체 회복, 겸직과 유물 효과 포함. 비용 부족은 부족분 표시.
- 사용/획득 때 배터리 전환과 숫자 이동은 180~240ms. 동작 줄이기 환경에서 생략.
- 1~3장 손패는 기본 상태에서 겹치지 않음. 3장에서 선택 확대로 폭이 부족해지면 좌우 탐색. 4~5장은 부채꼴, 6장 이상 좌우 탐색 유지.
- 손패 카드 높이 최대 228px, 이름/효과 가독성 강화. 작은 높이에서는 별도 축약 치수 적용.
- 카드 사용 가능 여부는 실제 비용·0코스트·초과근무 여부로 판정. 자동 턴 종료 없음.
- 적 행동은 이번 행동과 다음 예고를 분리. 보호 대상 표시. 모바일 피해 요약은 ‘이번 적 턴’.
- 회복 0인 결과는 평상시 안내에서 제외, 전투 기록 보존. 겸직 안내는 필요한 카드 계열을 표시.
- 화면 높이(안전 영역 제외) 640px 미만, 확대, 가로 화면에서는 기존 스크롤 모드 유지. 전투 규칙/저장 스키마 변경 없음.

## 검증 범위

JSDOM: 손패 1/2/3/5/8장, 잔량 0/1/2/3/4/7/12, 사용 불가·0코스트·초과근무·피로 카드, 미리보기 비변경, 에너지 소비/회복/이중계약서의 실제 결과 일치, 적 충전/보호/피해 표시, SVG 점등 칸 수 검사 통과.
기존 전투 연출·저장 복원 7그룹, 웹 빌드 자산 80개 해시 검사 통과.

브라우저 제한: 로컬 Chromium 다운로드 결과가 유효한 ZIP이 아니어서 설치 실패. 클라우드 브라우저는 file: URL을 보안 정책으로 거부. 로컬 QA 파일의 브라우저 실행은 하지 못했으며, 실기기 터치·모바일 픽셀 배치 검증으로 간주하지 않는다.

## 에셋 출처

직접 작성한 SVG 벡터 5종. 기존 UI의 금빛/보라색 계열을 사용. 숫자·문자는 SVG에 포함하지 않음. 이미지 생성 모델을 사용하지 않음.
에셋팩토리 audit_preview는 메타데이터 구조만 검수하며 시각/엔진/권리 검증을 대체하지 않음.
