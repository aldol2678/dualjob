# 패치 C · v0.6.24 구현 및 검증

2026-10-29 · 검토 후보. 운영 기준선은 B 패치 v0.6.23, main `23de40ec5db45febb81f3ef984f19ba1708c13a3`이다. 이 문서는 로컬 검증 시점의 기록이며 병합·운영 배포 완료를 뜻하지 않는다.

반복 플레이에서 연출 대기 시간을 선택하고, 카드의 비용과 효과를 되짚고, 같은 직업의 다른 전문화를 시도하기 쉽게 개선했다. 기존 카드·유물·전문화·지도와 연출 프레임을 재사용한다. 카드 효과, 비용, 적 수치, 경로 보상과 B의 카드 순환·보스 규칙은 유지한다.

최소 연출의 턴 종료 연속 입력은 200ms 동안 같은 행동을 중복 처리하지 않는다. 그 사이 카드를 사용했거나 구역이 바뀌면 다음 턴 종료를 허용한다. 애니메이션 재생은 이미 확정·저장한 전투를 보여주기만 하며, 건너뛰기나 속도 때문에 효과를 다시 실행하지 않는다.

전투 기록은 행동당 최대 40효과, 각 문자열 최대 500자로 제한한다. 초과 효과가 있으면 생략 안내를 표시한다. 전투를 새로 시작하면 해당 전투의 기록으로 교체한다. 미리보기는 복제 상태만 처리하므로 실제 기록을 추가하지 않는다. 전문화 미선택·이전 규칙 저장도 구분한다. 덱에서 제거한 카드의 강화 흔적은 최종 강화 목록에 포함하지 않는다. 이전 저장의 별도 융합 특전은 일반 강화와 따로 표시한다.

## 저장과 호환성

- 저장 키·패킷 schema 1·run version 4·contentRevision 21 유지.
- 선택 필드 `run.actionLog`, `settings.combatSpeed` 추가. 예전 기록에 없으면 빈 행동 기록·보통 속도를 사용한다.
- 예전 효과 로그에서 과거 행동 단위를 추측해 만들지 않는다. 기존 원문은 그대로 열 수 있다.
- 잘못된 행동 기록 구조·길이 또는 알 수 없는 백업 속도 값은 거부한다. 복원 전 검증 및 저장 실패 시 기존 기록 보존 흐름 유지.
- 종료된 도전은 기존 정책대로 진행 저장에서 제거한다. 새 빌드 요약은 현재 결과 화면에서 확인하는 기능이며, 새로고침 후 열 수 있는 영구 런 이력은 추가하지 않았다.
- 이전 코드로 돌아가도 게임 상태의 기존 필드는 유지된다. 운영 롤백·재업데이트는 실제로 수행하지 않았다.

## 남은 범위

실제 Android/iPhone 터치·주소창·전체화면, 오디오/FPS, 화면 읽기 프로그램과 200% 확대는 미검증이다. 로컬 Chromium의 모바일 터치 모사는 실기기 검증이 아니다. 테스트 환경에 일부 이모지 글리프가 없어 스크린샷의 장식 아이콘이 대체 문자로 보인다. 문구·버튼·게임 에셋의 배치 확인과 실제 기기 글리프 확인을 구분한다.

전문화별 효과 차이는 자동 검증했지만 사람이 같은 직업을 반복할 이유가 충분해졌는지는 아직 검증하지 않았다. 다음 실제 플레이에서는 빠름/최소를 골라도 발동 원인을 이해하는지, 결과의 대체 전문화를 보고 다음 도전에서 카드 선택을 바꾸는지 관찰한다. 별도 도전 모드·보상·직업·랭킹은 추가하지 않았다. B의 경로 보상 수치 조정은 계속 보류다.
