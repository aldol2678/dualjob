# ALDOL Game UI Kit · 겸직금지 시범 적용

## 범위와 원칙
- 목표: 한눈에 읽히는 게임 HUD, 선명한 조작 상태, 일관된 카드·버튼·정보 패널 디자인.
- 기본 색상은 게임 고유의 남색·보라·금색·민트 계열 유지. 참고 게임 이미지를 복제하지 않음.
- 기존 `src/assets/styles.css`와 `src/assets/game.js`는 수정하지 않음.
- 추가 스타일은 `src/assets/ui-kit.css` 하나로 분리. `src/index.html`에서 기존 CSS 다음에 불러옴.
- 기존 이미지, SVG, Pretendard, Gmarket 글꼴 재사용. 외부 CDN·새 런타임 의존성 없음.
- 복구 방법: `src/index.html`에서 `assets/ui-kit.css` 링크 제거. 시범 패치는 게임 저장·경제·카드 ID를 건드리지 않음.
- 게임 루트 `#app`은 동일 ID를 유지하고 의미론적 `main`으로 변경함.

## 시각 규격
| UI | 규칙 |
| --- | --- |
| 버튼 | 금색 주요 행동, 청록색 보조 행동, 적색 위험 행동. 초점 테두리·비활성 상태 표시. |
| 패널 | 공통 윤곽·윗면 하이라이트·그림자. 기존 배치와 크기는 유지. |
| 카드 | 비용, 이름, 설명 대비 강화. 선택·키보드 초점 표시. 카드 부채꼴 기하 유지. |
| HUD | 스테이지 현재/완료 상태, 의도·체력·메시지의 상태 대비 강화. |
| 모바일 | 기본 44px 터치 목표; 상단 좁은 버튼은 38–40px 기존 공간을 보존하는 타협. 확대/높이 부족/가로 모드에서 기존 스크롤 모드 유지. |
| 동작 | 모션 줄이기 설정 준수. 기존 카드 전투 움직임과 선택 동작을 변경하지 않음. |

## 검증 상태
- 정적 소스 확인: 기존 게임 JS SHA 동일, 기존 CSS 미수정, 새 CSS 링크 위치 확인, CSS 괄호 구조 확인.
- 본새 정적 분석: 신규 토큰·반응형 규칙·초점·비활성 상태 파악. 실제 화면 렌더링 검수와 대비 실측은 아직 아님.
- 미검증: 실제 Android 실기기, 브라우저 상 카드 선택/스크롤, 저장·이어하기, 가로/낮은 화면, 장시간 플레이, 다양한 브라우저.

## 브라우저 수용 점검표
1. 뷰포트 320×568, 360×640, 390×844, 430×932, 768×1024, 데스크톱 1280×800.
2. 390×~640, 700×~500, 가로 모드: 카드 손패/턴 종료/에너지 UI가 서로 겹치지 않는지.
3. 카드 1/3/5/8장: 선택 강조, 좌우 스크롤, 카드 비용/효과 가림, 드래그 후 탭 처리.
4. 직업 선택 → 전투 → 보상 카드/유물 → 이벤트 → 저장/백업 → 이어하기, 오류 화면.
5. 키보드 초점, 비활성 버튼, 모션 줄이기, 한국어 긴 단어 줄바꿈, 안전 영역(safe area).
6. 시각적 이득(가독성, 조작 가능성)이 부채꼴 기하·높이/폭 회귀보다 작은 경우 시범 도입 보류.

## 릴리스 조건
- 브라우저 스크린샷 및 탭/터치 확인, 기존 QA 회귀 검사 통과 전에는 병합·운영 배포 금지.
- GitHub Actions는 필수 검사로 전제하지 않음. 독립 실행/로컬 검사 사용.
- 현재 문서는 구현 후보에 대한 QA 안내이며 **배포 승인**이나 **전체 검수 완료**를 뜻하지 않음.
